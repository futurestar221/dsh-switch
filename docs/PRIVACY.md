# 隐私说明

dsh-switch 是本地 Windows 工具。它的目标是让 DSH 环境切换留在本机，而不是把数据
上传到服务器。

## 不收集什么

dsh-switch 本身不包含：

- 账号体系；
- 遥测、埋点或使用统计；
- 自动更新；
- 远程 API 调用；
- 云端同步。

项目不会主动把 HOME、聊天记录、登录信息、插件列表或日志发送到外部地址。

## 会读取哪些本地数据

在你打开界面或执行操作时，管理器可能读取：

- 你选择的 `DeepSeek Harness.exe` 路径；
- `%APPDATA%\dsh-manager` 中的管理器配置、实例表、日志和回收站记录；
- 你登记的环境 HOME 和 agents 目录；
- 环境中的 `profiles`、`package.json`、插件目录和技能元数据；
- 桌面和开始菜单中与 DSH 相关的快捷方式。

读取插件和技能信息用于界面展示，不会修改 DSH 程序文件。

## 会写入哪些本地数据

管理器会在 `%APPDATA%\dsh-manager` 写入配置、实例表、当前状态、端口文件、日志和
回收站记录。只有你明确执行新建、切换、迁移、删除、快捷方式隐藏等操作时，才会修改
对应的环境目录或快捷方式。

## 网络边界

界面和后台服务通过随机端口的 `127.0.0.1` 本地 HTTP 连接通信，不监听局域网地址。
`/api/*` 接口有同源来源检查，防止普通网页跨站调用本地接口。

桌面外壳使用 Microsoft Edge WebView2 Runtime；浏览器模式使用 Microsoft Edge。它们
是第三方系统组件，可能遵循 Microsoft 自己的隐私和诊断策略，不属于 dsh-switch 自身
的遥测功能。

## 日志和公开分享

日志用于排查路径、进程和服务错误，可能包含：

- Windows 用户名；
- HOME 和 agents 的完整路径；
- DSH 安装路径；
- 端口号和时间。

在公开 Issue、截图或聊天中分享日志前，请先删除个人路径、用户名、令牌和其他敏感
信息。建议只保留出错时间附近的相关行。

## 删除本地数据

关闭 dsh-switch 和 DSH 后，可以手动删除：

- `%APPDATA%\dsh-manager`：管理器配置、日志和回收站；
- 程序目录：程序本体和浏览器运行时目录；
- 你自行创建的 DSH HOME / agents。

删除管理器数据不会自动删除 DSH HOME。回收站一旦清空，里面的目录也会被真正删除，
请先确认并做好备份。
